InvoiceEditDialog — это WPF-окно для создания и редактирования счетов-фактур. Компонент состоит из двух файлов: XAML-разметки (Views/Dialogs/InvoiceEditDialog.xaml) и код-behind (Views/Dialogs/InvoiceEditDialog.xaml.cs, ~1350 строк).

## Архитектура и паттерны

**Code-behind сViewModel-подходом**: диалог реализует `INotifyPropertyChanged`, выступает в роли ViewModel и использует прямой DataContext = this. Класс напрямую управляет элементами UI (code-behind подход).

**Основные сервисы**:
- `MetadataService` — загрузка справочников, планов счетов, организаций, валют, налогов
- `InvoiceService` — бизнес-логика работы со счетами (получение, сохранение, пересчет сумм, генерация номеров)
- `AccountAnalyticsRegistry` — аналитика по счетам (отображение поля валюты)

**Режимы работы**:
- Новый документ (editId == null)
- Редактирование (editId.HasValue, isReadOnly = false)
- Просмотр (isReadOnly = true) — все поля disabled, скрыты кнопки управления строками, виден текст-подсказка

## Структура XAML (окно 980x680)

Layout: Grid с 7 строками. Конвертер `BooleanToVisibilityConverter` для gestion видимости.

**Заголовок (Row 0)**: DialogTitle — динамический заголовок в зависимости от режима.

**Шапка документа (Row 1)**: 8x2 Grid полей:
- Номер (TextBox)
- Дата (DatePicker — с пересчетом курса при смене)
- Организация (ComboBox с прикрепленным ReferencePickerControlFactory для поиска)
- Номер ЭСФ
- Счет стороны Б (TextBox + Button "..." — AccountSelectionDialog)
- Основание
- Серия и № бланка
- Модуль (автозаполнение из метаданных)
- Вид оплаты / Вид поставки ЭСФ
- НДС / Налог с продаж (ComboBox с ItemsSource="{Binding VatTaxItems/SalesTaxItems}")
- Тип поставки ЭСФ

**Валютная панель (Row 1, Grid.ColumnSpan=2, Visibility=Collapsed)**: показывается автоматически, если выбран валютный счет. Содержит: Валюта, Курс, Сумма в валюте.

**Таблица строк (Row 2, DataGrid LinesGrid)**:
Columns: Наименование, Счет стороны А (template с TextBox + Button), Без налогов, НДС (ComboBox), % НДС (read-only), Сумма НДС (read-only), Налог с прод. (ComboBox), % НП (read-only), Сумма НП (read-only), Итого (read-only). Привязки к свойствам `EditableInvoiceLine` с UpdateSourceTrigger=PropertyChanged. Visibility и IsEnabled кнопок выбора счета зависят от `IsInvoiceEditingEnabled`.

**Панель кнопок строк (Row 3)**:
- Добавить строку / Удалить строку / Проводки по строке / Все проводки / Пересчет
- DeleteLineButton и LinePostingsButton disabled при отсутствии выделения

**Итоги (Row 4)**: 4 колонки — Без налогов, НДС, Налог с продаж, Итого в нац.вал.

**Режим просмотра (Row 5)**: ModeHintText — серый italic текст, виден только в read-only режиме.

**Кнопки окна (Row 6)**: Запись (зеленая) / Отмена (серая).

## Ключевая логика и методы

### Инициализация (InitializeAsync)
1. Загрузка каталогов и справочников
2. Заполнение OrganizationCombo (с поиском через ReferenceComboBoxSearchHelper)
3. Загрузка плана счетов для диалога выбора
4. Загрузка справочников: Виды оплаты, Виды поставки, Типы поставки, Валюты, Налоги
5. Разделение налогов на VatTaxItems и SalesTaxItems по кодам/названиям
6. Если editId.HasValue — загрузка документа, заполнение полей, восстановление позиций, синхронизация налоговых контролов
7. Если новый документ — автономера, дата = сегодня, счета по умолчанию, дефолтные значения combo
8. RecalculateTotals и обновление видимости валютной панели

### Управление редактированием (DisableEditing/DisableReadOnlyMode)
- IsInvoiceEditingEnabled = false ld блокирует все контролы
- В read-only additionally скрываются AddLineButton/DeleteLineButton/RecalculateButton, меняется текст SaveButton на "Закрыть"

### Работа со строками
- **AddLine**: создание EditableInvoiceLine с дефолтными налогами из заголовка или предыдущей строки
- **OnDeleteLineClick**: удаление + перенумерация
- **OnLineSelectionChanged**: обновление состояния кнопок, синхронизация заголовка с выбранной строкой
- **SyncHeaderTaxControls**: синхронизация HeaderVatTaxCombo/HeaderSalesTaxCombo с выбранной строкой (или дефолт)

### Выбор счетов (OnSelectAccountClick/OnSelectLineAccountClick)
- Открытие AccountSelectionDialog
- Проверка: счет стороны А не должен совпадать со счетом стороны Б — если совпадает, подставляется дефолтный

### Пересчет (RecalculateTotals/RebuildDocumentFromForm)
- InvoiceService.RecalculateLine(line) — пересчет строки
- InvoiceService.RecalculateTotals(document) — итоги документа
- Обновление TotalWithoutTaxText, TotalVatText, TotalSalesTaxText, TotalAmountText
- RecalculateCurrencyAmount — пересчет суммы в валюте (TotalAmount / ExchangeRate)

### Валюты
- UpdateCurrencyPanelVisibility — показывать панель, если счет валютный (IsCurrencyAccount через AccountAnalyticsRegistry)
- ApplyExchangeRateFromCatalogAsync — автоматическая подстановка курса из справочника при смене валюты или даты
- KGS всегда имеет курс 1

### Налоги
- При смене VatTaxCode/SalesTaxCode в строке — ApplyTaxRate подставляет ставку из справочника
- Заголовочные комбо синхронизированы с выбранной строкой (HeaderVatTaxCombo/HeaderSalesTaxChanged)
- ResolveTaxCode — маппинг legacy-кодов на текущие справочники

### Сохранение (OnSaveClick)
- Валидация: номер, дата, минимум одна строка, валюта и курс если валютный счет
- BuildDocumentFromForm() — создание InvoiceDocument из полей
- _invoiceService.SaveInvoiceAsync(document, _editId) — сохранение

## Вспомогательные типы

**ReferenceOption**: record класс для элементов справочников (Value, DisplayName, Rate, SortOrder, IsDefault, IsDefaultVat, IsDefaultSalesTax, Code)

**OrganizationItem**: класс с Id, DisplayName, HashSet<string> LookupKeys — для быстрого поиска организаций

**EditableInvoiceLine**: наследуется от InvoiceLineRow, переопределяет свойства для INotifyPropertyChanged. Добавляет AccountDisplayName. Метод NotifyCalculatedProperties() уведомляет UI о пересчитанных суммах.

## Утилитарные методы
- GetRowValue/GetDecimal/GetInt/GetBool — безопасное получение значений из словаря
- SelectComboValue/SelectDefaultReference/SelectStoredComboValue — selection logic
- NormalizeLegacyDeliveryKind/NormalizeLegacySupplyKind — маппинг старых значений
- FocusAmountCell — выделение ячейки "Без налогов" при добавлении строки
- BuildCodeName — формат "Код - Наименование"

## Отклики на события
- DatePicker.SelectedDateChanged → ApplyExchangeRateFromCatalogAsync (пересчет курса)
- TextBox AmountCurrencyBox/ExchangeRateBox.TextChanged → RecalculateTotals
- ComboBox НДС/НП в заголовке → изменение выбранной строки
- LinesGrid.SelectionChanged → SyncHeaderTaxControls, обновление кнопок

Диалог демонстрирует комплексный подход к работе с финансовыми документами: валидация, пересчеты, поддержка валют, интеграция с планом счетов, синхронизация заголовка и строк, режимы просмотра/редактирования.
