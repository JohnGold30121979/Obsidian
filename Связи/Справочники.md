## 📌 **НАЗНАЧЕНИЕ CatalogDataView**

**`CatalogDataView`** — это универсальный WPF `UserControl` для **просмотра, поиска, добавления, редактирования, удаления, экспорта и импорта данных справочников** в системе BIS.ERP. Он является основным интерфейсом для работы с любым справочником системы, динамически строя таблицу на основе метаданных.

---

## 🎯 **ЧТО ДЕЛАЕТ (ФУНКЦИОНАЛ)**

### 1. **Загрузка и отображение данных** (`LoadData`)
- Получает все записи справочника через `_metadataService.GetCatalogDataAsync(_catalog.Id)`
- Загружает все справочники системы для подстановки имен в Reference-поля
- Строит `DataTable` динамически: колонки = поля из `MetadataObject.Fields`
- Для Reference-полей подставляет `DisplayName` вместо ID (через `_referenceCache`)
- Отображает данные в `DataGrid` с настроенными колонками

### 2. **Фильтрация полей** (`GetUniqueCatalogFields`)
- Для "План счетов" — строго определенный набор колонок (code, name, account_type, closing_module_code и др.)
- Для "Авансовые платежи" — свой набор колонок
- Удаляет дубликаты по `DbColumnName` и `Name`

### 3. **Поиск по справочнику** (`ApplySearchFilter`)
- Фильтрация по всем видимым колонкам через `DataTable.DefaultView.RowFilter`
- Экранирование спецсимволов для безопасного поиска
- Отображение количества найденных записей

### 4. **CRUD операции**

| Операция | Метод | Что делает |
|---|---|---|
| **Добавление** | `OnAddClick` | Открывает `CatalogItemDialog` → вызывает `_metadataService.AddCatalogItemAsync` |
| **Редактирование** | `OnEditClick` | Открывает `CatalogItemDialog` с existingData → вызывает `_metadataService.UpdateDynamicRecordAsync` |
| **Удаление** | `OnDeleteClick` | Подтверждение → вызывает `_metadataService.DeleteDynamicRecordAsync` |
| **Обновление** | `OnRefreshClick` | Перезагружает данные |

### 5. **Экспорт в Excel** (`OnExportClick`)
- Использует библиотеку **ClosedXML** (`XLWorkbook`)
- Экспортирует `DataTable` в `.xlsx` файл
- Форматирует заголовки (жирный, белый текст, темный фон)
- Автоподбор ширины колонок
- Предлагает открыть файл после сохранения

### 6. **Импорт из DBF** (`OnImportDbfClick`)
- Доступен только для "План счетов" (BUXSCH.DBF) и "Классификация платежей" (VID_PL.DBF)
- Для плана счетов: `_metadataService.ImportChartOfAccountsFromDbfAsync`
- Для классификации: `_metadataService.ImportPaymentClassificationsFromDbfAsync`
- Показывает детальный отчет о результате импорта

### 7. **Специализированные конвертеры для отображения**

| Конвертер | Для чего |
|---|---|
| `AccountTypeDisplayConverter` | Тип счета: Active → "Активный", Passive → "Пассивный" |
| `BooleanYesNoDisplayConverter` | Bool → "Да"/"Нет" через `LocalizationService` |
| `BooleanPlusDisplayConverter` | Bool → "+" / "" (для флагов связей) |
| `ClosingModuleDisplayConverter` | Код модуля → отображаемое имя |
| `ChartOfAccountsModeDisplayConverter` | Признак печати / Сохранять остатки → отображаемое значение |

### 8. **Специализированные заголовки колонок**
- Для "План счетов" — сокращенные заголовки с переносом строк (например "Тип\nсчета", "Связь\nс орг.")
- Для "Авансовые платежи" — свои сокращения ("Модуль", "Разн. расч.", "Анал. плат.")

### 9. **Ширина колонок**
- Для "План счетов" — точные пиксельные размеры для каждой колонки
- Для "Авансовые платежи" — свои размеры
- Для остальных справочников — `Star` (равномерное распределение)

## 🔗 **ЗАВИСИМОСТИ (DEPENDENCIES)**

### **Модели (Models)**

| Класс | Где используется | Для чего |
|---|---|---|
| `MetadataObject` | Поле `_catalog` | Метаданные справочника: имя, поля, тип объекта |
| `MetadataField` | `GetUniqueCatalogFields()`, `CreateDataGridColumn()` | Описание поля: имя, тип, ReferenceCatalog, DisplayPattern |
| `ChartOfAccountsDbfImportResult` | `BuildChartOfAccountsImportMessage()` | Результат импорта плана счетов из DBF |
| `PaymentClassificationDbfImportResult` | `BuildPaymentClassificationImportMessage()` | Результат импорта классификации платежей из DBF |

### **Сервисы (Services)**

| Сервис | Где используется | Для чего |
|---|---|---|
| `MetadataService` | Основной сервис (поле `_metadataService`) | Получение данных справочников, CRUD операции, импорт DBF |
| `LocalizationService` | В конвертерах `AccountTypeDisplayConverter`, `BooleanYesNoDisplayConverter` | Локализация значений (Active → Активный, true → Да) |
| `ChartOfAccountsSelectionMetadata` | `ClosingModuleDisplayConverter`, `ChartOfAccountsModeDisplayConverter` | Нормализация отображения модулей и режимов |

### **Другие View-компоненты**

| Компонент | Где используется | Для чего |
|---|---|---|
| `CatalogItemDialog` | `OnAddClick()`, `OnEditClick()` | Диалог добавления/редактирования записи справочника |

### **Внешние библиотеки (NuGet)**

| Библиотека | Где используется | Для чего |
|---|---|---|
| `ClosedXML` | `ExportToExcel()` | Создание и форматирование Excel-файлов (.xlsx) |

### **WPF/System компоненты**

| Компонент | Где используется | Для чего |
|---|---|---|
| `DataGrid` | Основной элемент | Отображение табличных данных |
| `DataTable` / `DataView` | `_dataTable`, `_dataTable.DefaultView` | Хранение и фильтрация данных |
| `IValueConverter` | 5 внутренних конвертеров | Преобразование значений для отображения |
| `OpenFileDialog` | `OnImportDbfClick()` | Выбор DBF файла для импорта |
| `SaveFileDialog` | `OnExportClick()` | Выбор пути для экспорта Excel |

## 🏗️ **АРХИТЕКТУРА ВЗАИМОДЕЙСТВИЯ**

```
CatalogDataView (UserControl)
  │
  ├── MetadataService ──── MetadataObject (справочник)
  │                           └── MetadataField[] (поля)
  │
  ├── DataTable (динамическое построение)
  │     ├── Колонки = поля справочника
  │     ├── Reference-поля → подстановка DisplayName через _referenceCache
  │     └── RowFilter = поиск по всем колонкам
  │
  ├── DataGrid (отображение)
  │     ├── Конвертеры для Bool, Тип счета, Модуль, Режимы
  │     ├── Спец. заголовки для План счетов / Авансовые платежи
  │     └── Пиксельные ширины для спец. справочников
  │
  ├── CRUD:
  │     ├── OnAddClick → CatalogItemDialog → AddCatalogItemAsync
  │     ├── OnEditClick → CatalogItemDialog → UpdateDynamicRecordAsync
  │     └── OnDeleteClick → DeleteDynamicRecordAsync
  │
  ├── Экспорт: ClosedXML → .xlsx
  │
  └── Импорт DBF:
        ├── План счетов → ImportChartOfAccountsFromDbfAsync
        └── Классификация платежей → ImportPaymentClassificationsFromDbfAsync
```

## 💡 **КЛЮЧЕВЫЕ ОСОБЕННОСТИ**

1. **Универсальность** — один контрол для всех справочников системы
2. **Динамическое построение таблицы** — колонки создаются на лету по метаданным
3. **Подстановка имен Reference** — вместо ID показывает человекочитаемые названия из связанных справочников
4. **Специализированная логика** — для "План счетов" и "Авансовые платежи" своя настройка колонок, заголовков, ширины
5. **Поиск по всем колонкам** — фильтрация через DataTable.RowFilter с экранированием
6. **Экспорт в Excel** — через ClosedXML с форматированием
7. **Импорт из FoxPro DBF** — для плана счетов и классификации платежей
8. **5 встроенных конвертеров** — для правильного отображения типов счетов, булевых значений, модулей
9. **Интеграция с CatalogItemDialog** — добавление и редактирование через тот же диалог
