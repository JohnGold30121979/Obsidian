## 📌 **НАЗНАЧЕНИЕ PostingDetailsDialog**

**`PostingDetailsDialog`** — это модальное окно (WPF `Window`) для **просмотра детальной информации о бухгалтерской проводке**. Отображает все атрибуты проводки в read-only режиме: счета дебета/кредита, суммы, валюту, организацию, сотрудника и другие реквизиты.

---

## 🎯 **ЧТО ДЕЛАЕТ (ФУНКЦИОНАЛ)**

### 1. **Динамическое построение формы** (`BuildDetails`)
- Принимает `PostingViewModel` и динамически строит Grid с 2 колонками (метка | значение)
- Скрывает поля с пустыми/нулевыми значениями
- Добавляет разделители между строками

### 2. **Отображаемые поля**

| № | Поле (Label) | Свойство PostingViewModel | Формат / Условие |
|---|---|---|---|
| 1 | **Документ** | `DocumentNumber` | Текст |
| 2 | **Дата** | `Date` | `dd.MM.yyyy HH:mm` |
| 3 | **Модуль** | `ModuleName` | "нет данных" если пустой |
| 4 | **Дебет** | `DebitAccount + DebitAccountName` | `"Код - Наименование"` |
| 5 | **Кредит** | `CreditAccount + CreditAccountName` | `"Код - Наименование"` |
| 6 | **Операция** | `Direction` | Текст |
| 7 | **Сумма (сом)** | `Amount` | `N2` |
| 8 | **Сумма (валюта)** | `AmountCurrency` | `N2`, только если > 0 |
| 9 | **Валюта** | `Currency` | Текст |
| 10 | **Организация** | `Organization` | С переносом строк |
| 11 | **Сотрудник** | `Employee` | С переносом строк |
| 12 | **Создана** | `CreatedAt` | `dd.MM.yyyy HH:mm` |
| 13 | **Статус** | `IsActive` | "Активна" / "Отключена" |
| 14 | **Примечание** | `Note` | С переносом строк |

### 3. **Форматирование заголовка окна**
- `TitleText` = `"📋 {DocumentType} №{DocumentNumber}"` (например "📋 Кассовый ордер №123")
- Если `DocumentType` пустой → `"📋 Проводка №{DocumentNumber}"`
- `Title` окна = `"Детали проводки №{DocumentNumber}"`

### 4. **Скрытие пустых полей**
- Если значение `null`, `empty` или `whitespace` — строка не добавляется в Grid
- `AmountCurrency` отображается только если > 0

### 5. **Закрытие**
- Кнопка "Закрыть" → `Close()`

## 🔗 **ЗАВИСИМОСТИ (DEPENDENCIES)**

### **Модели (Models)**

| Класс | Где используется | Для чего |
|---|---|---|
| `PostingViewModel` | Конструктор `PostingDetailsDialog(PostingViewModel posting)` | Модель представления проводки со всеми отображаемыми полями |

### **Где используется PostingDetailsDialog (потребители)**

| Модуль | Файл | Для чего |
|---|---|---|
| **PostingsView** | `Views/PostingsView.xaml.cs` | Просмотр деталей проводки из общего журнала проводок |
| **PostingsJournalView** | `Views/PostingsJournalView.xaml.cs` | Просмотр деталей проводки из журнала проводок |
| **CashOrderWorkView** | `Views/CashOrderWorkView.xaml.cs` | Просмотр проводки, связанной с кассовым ордером |

### **Свойства PostingViewModel, используемые в диалоге**

```
PostingViewModel
├── DocumentNumber      → TitleText + заголовок
├── Date                → "Дата" (dd.MM.yyyy HH:mm)
├── DocumentType        → TitleText (тип проводки)
├── ModuleName          → "Модуль" (или "нет данных")
├── DebitAccount        → "Дебет" (через FormatAccount)
├── DebitAccountName    → "Дебет" (через FormatAccount)
├── CreditAccount       → "Кредит" (через FormatAccount)
├── CreditAccountName   → "Кредит" (через FormatAccount)
├── Direction           → "Операция"
├── Amount              → "Сумма (сом)" (N2)
├── AmountCurrency      → "Сумма (валюта)" (N2, только > 0)
├── Currency            → "Валюта"
├── Organization        → "Организация"
├── Employee            → "Сотрудник"
├── CreatedAt           → "Создана" (dd.MM.yyyy HH:mm)
├── IsActive            → "Статус" ("Активна"/"Отключена")
└── Note                → "Примечание"
```

## 💡 **КЛЮЧЕВЫЕ ОСОБЕННОСТИ**

1. **Read-only режим** — только просмотр, никаких изменений
2. **Динамическое построение** — Grid строится программно, скрывает пустые поля
3. **Форматирование дат** — `dd.MM.yyyy HH:mm`
4. **Форматирование сумм** — `N2` (с двумя знаками после запятой)
5. **Локализация статуса** — `IsActive` → "Активна" / "Отключена"
6. **Объединение счета** — `FormatAccount()` объединяет код и наименование в одну строку
7. **Современный дизайн** — белые Border-блоки, скругленные углы, серый фон окна
8. **ScrollViewer** — поддержка прокрутки при большом количестве данных
9. **Используется в 3 модулях** — централизованный просмотр деталей проводки
10. **Простая архитектура** — без ViewModel, без Binding, прямое присвоение в code-behind
