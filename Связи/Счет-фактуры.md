InvoiceWorkView — это UserControl (модуль рабочей области) для управления счетами-фактурами в приложении BIS.ERP. Модуль состоит из XAML-разметки (Views/InvoiceWorkView.xaml) и код-behind (Views/InvoiceWorkView.xaml.cs, 364 строки).

## Архитектура и назначение

**Тип**: UserControl (встраиваемый модуль)
**Режимы работы**: determined by metadata
- **Режим продажи** (`_isSalesMode = true`) — стандартный модуль счетов-фактур продажи
- **Режим регистрации** (`_isRegistrationMode = true`) — специальный режим для регистрации счетов-фактур по НДС (покупка)

## Структура XAML (Grid, 6 строк)

### Заголовок (Row 0)
- **TitleText** — крупный заголовок (24px, bold), показывает название документа из метаданных

3. **DeleteButton** — "🗑️ Удалить" (красная, disabled) — удалить непроведенный
4. **AllPostingsButton** — "📒 Все проводки" (бирюзовая, disabled) — показать проводки
5. **PrintButton** — "🖨 Печатная форма" (темно-синяя, disabled) — печать PDF
6. **ExportEsfButton** — "📤 Выгрузка ЭСФ" (фиолетовая) — экспорт в XML (только для продажи)
7. **ImportEsfButton** — "📥 Загрузка ответа" (серая) — импорт ответа налоговой (только для продажи)
8. **RefreshButton** — "🔄 Обновить" (серая) — перезагрузка данных

### Таблица счетов (Row 2, DataGrid InvoicesGrid)

- Документ (номер)

`IsReadOnly="True"` — отображает позиции выбранного счета

- Счет (AccountName, скрыт в режиме регистрация)
- Сумма б/нал
- НДС
- Налог с прод (скрыт в режиме регистрация)
- Итого

### StatusBar (Row 5)
- **StatusText** — статус операции
- Подсказка: "двойной щелчок по счет-фактуре открывает просмотр без изменения данных"

## Ключевая логика код-behind

### Инициализация (OnLoaded)
Асинхронная загрузка при открытии модуля:
1. Получение DbContext через ServiceLocator.InfoBaseManager
2. Создание InvoiceMetadataSeedService и вызов EnsureAsync() — гарантирует наличие метаданных
3. Создание InvoiceService и конфигурация через _documentMetadata
4. EnsureSchemaAsync() — гарантирует наличие таблиц в БД
5. Создание InvoiceEsfExchangeService для работы с ЭСФ (только для продажи)
6. LoadDataAsync() — загрузка счетов

### Режимы UI (ConfigureModeUi)
Для режима регистрации:
- Заголовок: "Регистрация счет-фактур по НДС"
- Описание: "Реестр зарегистрированных счетов-фактур..."
- AddButton: "➕ Добавить счет-фактуру" (ширина 165)
- EditButton: "✏ Изменить" (ширина 120)
- Показываются колонки: Серия и № бланка, Модуль, ЕдИз, Кол-во
- Скрываются: Номер ЭСФ, Статус ЭСФ, Основание, Счет (в строках), Налог с прод
- Скрываются кнопки: ExportEsfButton, ImportEsfButton

### Состояния кнопок (UpdateButtonsState)
- EditButton: enabled если есть выделенная строка
- DeleteButton: enabled если есть выделенная строка И IsPosted == false (нельзя удалить проведенный)
- AllPostingsButton: enabled если есть выделение
- PrintButton: enabled если есть выделение
- ExportEsfButton/ImportEsfButton: enabled только в режиме продажи

### Загрузка данных (LoadDataAsync)
1. StatusText = "Загрузка..."
2. EnsureSavedInvoicesPostedAsync() — автоматически проводит непроведенные сохраненные счета
3. GetInvoicesAsync() — получает список счетов
4. Привязка к InvoicesGrid.ItemsSource
5. Очистка LinesGrid.ItemsSource
6. StatusText показывает количество документов и сколько автоматически проведено

### Работа с выбором (OnInvoiceSelectionChanged)
При изменении выделения:
- UpdateButtonsState()
- Если есть выделение — загружаем строки через GetLinesAsync(selected.Id) и привязываем к LinesGrid

### Операции CRUD
**Add (OnAddClick)**:
- Создает InvoiceEditDialog (без editId — новый документ)
- При успешном ShowDialog() (true) — перезагружает данные

**Edit (OnEditClick)**:
- Открывает InvoiceEditDialog с editId, isReadOnly=false
- При успешном сохранении — перезагружает данные

**Double-click (OnInvoiceDoubleClick)**:
- Открывает InvoiceEditDialog с editId, isReadOnly=true (просмотр)

**Delete (OnDeleteClick)**:
- Подтверждение YesNo
- DeleteInvoiceAsync(selected.Id)
- Перезагрузка данных

### Проводки (OnAllPostingsClick)
- Создает PostingService
- GetPostingsByDocumentAsync(_documentMetadata.Name, selected.DocNumber, selected.DocDate)
- Открывает DocumentPostingsDialog

### Печать (OnPrintClick)
1. Check: выбран ли счет
2. Создает PrintFormService
3. SeedInvoiceFormsAsync() — гарантирует наличие печатных форм
4. GetPrintFormsAsync(_documentMetadata.Id) — получает доступные формы
5. Если нет форм — предупреждение
6. PrintFormSelectionDialog — выбор формы
7. ExportInvoiceDocumentAsync(report, selected.Id) — генерация PDF
8. PdfPreviewWindow —预览 PDF

### Выгрузка ЭСФ (OnExportEsfClick)
- Только для режима продажи
- InvoiceEsfExportDialog — выбор режима (выбранный/период)
- SaveFileDialog — выбор файла
- ExportSelectedInvoicesAsync или ExportPeriodAsync
- Перезагрузка данных, MessageBox с результатом

### Загрузка ответа ЭСФ (OnImportEsfClick)
- Только для режима продажи
- OpenFileDialog — выбор XML файла
- ImportResponseAsync(fileName)
- Перезагрузка данных
- MessageBox с статистикой: всего записей, обновлено, не сопоставлено

## Особенности реализации

1. **Автопроведение**: при загрузке автоматически проводятся непроведенные сохраненные счета (EnsureSavedInvoicesPostedAsync)
2. **Двойной щелчок**: открывает просмотр (isReadOnly=true), а не редактирование
3. **Удаление только непроведенных**: DeleteButton.IsEnabled = hasSelection && selected?.IsPosted == false
4. **Конфигурируемость через метаданные**: UI адаптируется под тип документа (продажа/регистрация)
5. **Реактивный StatusBar**: показывает статус операций, количество документов, ошибки
6. **ESF функционал**: доступен только для продажи (импорт/экспорт ответов)

Модуль представляет собой типичный Master-Detail интерфейс: список документов сверху, детализация по строкам снизу, с полным циклом операций (создание, редактирование, удаление, проводка, печать, интеграция с ЭСФ).
