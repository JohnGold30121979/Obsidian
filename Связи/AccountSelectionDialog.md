## 📌 **НАЗНАЧЕНИЕ AccountSelectionDialog**

**`AccountSelectionDialog`** — это модальное окно (WPF `Window`) для **выбора бухгалтерского счета из плана счетов**. Оно предоставляет удобный интерфейс поиска и выбора счета с отображением кода, наименования, типа и статуса активности.

---

## 🎯 **ЧТО ДЕЛАЕТ (ФУНКЦИОНАЛ)**

### 1. **Отображение списка счетов**
- Принимает `List<Dictionary<string, object>>` — список счетов в виде словарей
- Конвертирует в `DataTable` с колонками: **Код**, **Наименование**, **Тип счета**, **Активен**, **Id** (скрытая)
- Отображает в `DataGrid` с 3 видимыми колонками + скрытая колонка Id

### 2. **Поиск по счетам** (`SearchBox_TextChanged`)
- Фильтрация списка в реальном времени при вводе текста
- Поиск по **коду счета** (с поддержкой цифрового поиска — можно ввести часть цифр кода)
- Поиск по **наименованию** счета
- Поиск по **типу счета** (Активный/Пассивный/Активно-пассивный)
- Если найдены совпадения — автоматически выделяет первую запись

### 3. **Умный поиск по цифрам** (`MatchesAccountSearch`, `ExtractDigits`, `ContainsDigitsInOrder`)
- Извлекает только цифры из поискового запроса
- Проверяет, содержатся ли эти цифры в коде счета **в том же порядке**
- Пример: поиск "101" найдет счет "1010", "1011", "1101" и т.д.

### 4. **Выбор счета**
- **Кнопка "Выбрать"** — подтверждает выбор
- **Двойной клик по строке** — мгновенный выбор
- **Кнопка "Отмена"** — закрывает без выбора
- После выбора: сохраняет оригинальный словарь счета в `SelectedAccount`, устанавливает `DialogResult = true`

### 5. **Форматирование отображения**
- **Тип счета**: через `LocalizationService.DisplayValue` (Active → "Активный", Passive → "Пассивный")
- **Активен**: через `LocalizationService.DisplayValue` (true → "Да", false → "Нет")

### 6. **Валидация выбора**
- Если строка не выбрана при нажатии "Выбрать" — показывает предупреждение "Выберите счет из списка!"
- Если выбранный Id не найден в оригинальном списке — показывает ошибку

## 🏗️ **АРХИТЕКТУРА ВЗАИМОДЕЙСТВИЯ**

```
AccountSelectionDialog
  │
  ├── Вход: List<Dictionary<string, object>> accounts
  │         (каждый словарь содержит: Id, Код, Наименование, Тип счета, Активен)
  │
  ├── ConvertToDataTable() → DataTable (Код | Наименование | Тип счета | Активен | Id)
  │
  ├── DataGrid (отображение)
  │     ├── Поиск: SearchBox_TextChanged → RowFilter по Id
  │     └── Умный поиск по цифрам кода (ExtractDigits + ContainsDigitsInOrder)
  │
  ├── Выбор:
  │     ├── Кнопка "Выбрать" / Двойной клик → SelectCurrentAccount()
  │     └── Находит оригинальный словарь → возвращает через SelectedAccount
  │
  └── Потребители:
        ├── AccountPickerControlFactory → при выборе счета из контрола
        ├── CashOrderDialog → кассовые ордера
        ├── FinanceDocumentDialog → фин. документы
        ├── InvoiceEditDialog → счета-фактуры
        ├── PaymentOrderDialog → платежные поручения
        └── AccountingSetupView → настройка бухучета
```

## 💡 **КЛЮЧЕВЫЕ ОСОБЕННОСТИ**

1. **Специализированный поиск по цифрам** — можно искать счет по частичному коду, цифры ищутся в порядке ввода (например "101" найдет все счета, содержащие эти цифры последовательно)
2. **Локализация** — типы счетов и статусы отображаются на русском языке через `LocalizationService`
3. **Скрытый Id** — колонка Id присутствует в DataTable, но не отображается, используется для точной идентификации счета
4. **Двойной клик** — поддерживает быстрый выбор без использования кнопок
5. **Автовыделение при поиске** — при фильтрации автоматически выделяется первый найденный счет
6. **Валидация** — проверка что счет выбран, проверка соответствия оригинальным данным
7. **Используется в 6+ модулях** — централизованный диалог выбора счета для всей системы
