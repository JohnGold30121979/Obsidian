PostingSearchDialog — это специализированное WPF-окно для поиска и выбора проводки из набора бухгалтерских проводок. Компонент состоит из XAML (Views/Dialogs/PostingSearchDialog.xaml, 42 строки) и код-behind (Views/Dialogs/PostingSearchDialog.xaml.cs, 69 строк).

## Архитектура и назначение

**Тип**: Window (модальный диалог выбора)
**Назначение**: преднастроенный селектор проводок с фокусом на бухгалтерские операции (дебет/кредит/сумма/примечание)
**Формат данных**: `List<Dictionary<string, object>>` — ожидает структурированные данные проводок

## Структура XAML (450x700, CenterOwner)

**Grid layout**: 3 строки

1. **Панель поиска (Row 0, StackPanel)**:
   - SearchBox (Width=300) — TextBox для ввода запроса
   - Кнопка "🔍 Поиск" (Width=80, оранжевая) — автоматически вызывает поиск при нажатии Enter в TextBox (через TextChanged)

2. **Результаты поиска (Row 1, DataGrid SearchResultsGrid)**:
   `AutoGenerateColumns="False"`, фиксированные колонки:
   - Дата (dd.MM.yyyy) — Binding `[Дата]`
   - Номер — Binding `[Номер документа]`
   - Дебет — Binding `[Дебет]`
   - Кредит — Binding `[Кредит]`
   - Сумма — Binding `[Сумма в сом]`
   - Примечание (Width=200) — Binding `[Примечание]`
   
   Особенности:
   - `MouseDoubleClick` — мгновенный выбор проводки
   - AlternatingRowBackground — визуальное разделение строк

3. **Футер (Row 2, StackPanel)**:
   - StatusText (слева) — статус "Готово" или "Найдено: N"
   - Кнопка "Выбрать" (зеленая, Width=80) — подтверждение выбора
   - Кнопка "Отмена" (красная, Width=80) — закрытие без выбора

## Ключевая логика код-behind

### Конструктор
Принимает `List<Dictionary<string, object>> postings` и сохраняет в `_postings`. Устанавливается начальный ItemsSource.

### Поиск (OnSearchClick)
Обрабатывается два события: TextChanged (при вводе) и Click (при нажатии кнопки).

**Алгоритм фильтрации** (case-insensitive):
```csharp
var results = _postings.Where(p =>
    (p.ContainsKey("Номер документа") && p["Номер документа"]?.ToString().ToLower().Contains(searchText) == true) ||
    (p.ContainsKey("Дебет") && ...) ||
    (p.ContainsKey("Кредит") && ...) ||
    (p.ContainsKey("Сумма в сом") && ...) ||
    (p.ContainsKey("Примечание") && ...) ||
    (p.ContainsKey("Организация") && ...)
).ToList();
```

**Особенности**:
- Пустой поиск (whitespace/null) — возвращает полный список, StatusText="Готово"
- При наличии результатов — StatusText показывает количество найденных
- Поиск идет по 6 полям: номер документа, дебет, кредит, сумма, примечание, организация
- Используется `ToLower()` для case-insensitive сравнения

### Выбор проводки
**SelectItem logic** (вызывается из двух мест):
1. OnSelectClick (кнопка "Выбрать")
2. SearchResultsGrid_MouseDoubleClick (двойной клик по строке)

Логика:
```csharp
SelectedPosting = SearchResultsGrid.SelectedItem as Dictionary<string, object>;
if (SelectedPosting != null)
{
    DialogResult = true;
    Close();
}
```

**Важно**: диалог возвращает `SelectedPosting` (property) — выбранную проводку как словарь.

### Отмена (OnCancelClick)
Устанавливает DialogResult=false, закрывает окно.

## Паттерн использования

Диалог используется в модулях для поиска проводок:
```csharp
var searchDialog = new PostingSearchDialog(postings);
if (searchDialog.ShowDialog() == true)
{
    var selectedPosting = searchDialog.SelectedPosting;
    // обработка выбранной проводки
}
```

**Контекст использования**:
- DocumentPostingsDialog — для детального просмотра проводок
- FinanceDocumentWorkView — привязка проводок к документам
- CashOrderWorkView — работа с кассовыми ордерами
- PaymentOrderWorkView — работа с платежными поручениями

## Отличия от ReferenceSelectionDialog

| Характеристика | ReferenceSelectionDialog | PostingSearchDialog |
|-----------------|-------------------------|---------------------|
| **Назначение** | Универсальный выбор записей | Специализированный поиск проводок |
| **Фильтрация** | Глобальный поиск по всем полям (Value.ToString) | Фиксированный набор полей (Номер, Дебет, Кредит, Сумма, Примечание, Организация) |
| **Колонки** | Динамические (на основе ключей) | Фиксированные в XAML |
| **Привязка** | Binding `[key]` | Binding `[Конкретное русское поле]` |
| **Событие поиска** | TextChanged (живой поиск) | TextChanged + Click (можно ввести и нажать) |
| **Кнопка Выбрать** | Только при выделении | Всегда видна, работает при выделении |

## Особенности реализации

1. **Специализированные поля**: жестко заданы русские названия полей проводок — диалог не универсален, но адаптирован под конкретный контекст учета
2. **Живой поиск** — поиск выполняется при каждом нажатии клавиши (TextChanged)
3. **Обработка пустого запроса** — возвращает полный список при пустом поиске
4. **Защита от null/отсутствия ключей**: проверки `ContainsKey` перед обращением
5. **Двойной клик** — ускорение выбора без нажатия кнопки
6. **Статусная информация** — количество найденных записей визуализировано в StatusText

## Расширяемость

Для добавления новых полей поиска:
1. Добавить проверку ключа в OnSearchClick
2. Добавить колонку в XAML (опционально)
3. Изменить StatusText для уточнения критериев

Для изменения формата даты — изменить StringFormat в XAML колонке "Дата".

Диалог представляет собой простой, но эффективный инструмент для быстрого поиска проводок по множеству полей с минимальным кодом и понятным UI.
