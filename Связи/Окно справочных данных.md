ReferenceSelectionDialog — это универсальное WPF-окно для выбора записи из списка справочных данных. Компонент состоит из XAML (Views/Dialogs/ReferenceSelectionDialog.xaml, 27 строк) и code-behind (Views/Dialogs/ReferenceSelectionDialog.xaml.cs, 206 строк).

## Архитектура и назначение

**Тип**: Window (модальный диалог)
**Универсальность**: работает с любыми данными в формате `List<Dictionary<string, object>>` — может отображать любые справочники, планы счетов, организации и т.д.

## Структура XAML (450x600, CenterOwner)

**Grid layout**: 3 строки
1. **SearchBox** (Row 0) — TextBox для поиска с ToolTip
2. **ItemsGrid** (Row 1) — DataGrid с AutoGenerateColumns="True" (исходная настройка, в коде переопределяется)
3. **Кнопки** (Row 2) — SelectButton (isDefault, по умолчанию disabled) + CancelButton

## Ключевая логика код-behind

### Конструктор
Принимает:
- `items` — список словарей с данными
- `firstField` — первое поле для отображения (опционально)
- `secondField` — второе поле (опционально)

### Динамическое создание колонок (автоконфигурация)
Алгоритм построения колонок DataGrid:

1. **Сбор всех ключей** из всех словарей (`SelectMany(d => d.Keys).Distinct()`)
2. **Фильтрация** — исключаются служебные поля: `CreatedAt`, `UpdatedAt`, `CreatedBy`, `UpdatedBy`, `IsDeleted`, `Id`
3. **Приоритизация** — если переданы `firstField` и/или `secondField`:
   - `firstField` помещается на первое место
   - `secondField` на второе (если не совпадает с firstField)
4. **Создание колонок** — для каждого ключа создается `DataGridTextColumn` с привязкой через `CreateValueBinding(key)`
5. **Fallback** — если колонок нет, добавляется колонка "Id"

### Поиск (SearchBox_TextChanged)
- trimming, case-insensitive поиск по всем значениям словарей
- Фильтрация: `item.Values.Any(v => v?.ToString()?.Contains(search) == true)`
- Обновление `ItemsGrid.ItemsSource = _filteredItems`

### Выбор
- **SelectionChanged** — активирует SelectButton при наличии выделения
- **MouseDoubleClick** — мгновенный выбор (вызов SelectItem())
- **SelectItem()** — сохраняет `SelectedItem`, устанавливает `DialogResult = true`, закрывает окно

### Привязка данных (CreateValueBinding)
Используется специальный `ReferenceGridValueConverter`:
- Для поля "Активен"/"is_active" — преобразует boolean в строки "Активен"/"Неактивен"
- Для остальных полей — возвращает значение как есть (или пустую строку)

## Использование в проекте

Диалог используется в InvoiceEditDialog для выбора счета:
```csharp
var dialog = new AccountSelectionDialog(_accounts);
if (dialog.ShowDialog() == true && dialog.SelectedAccount != null)
{
    var accountCode = dialog.SelectedAccount.GetValueOrDefault("Код")?.ToString();
}
```

## Особенности реализации

1. **Полная автоматизация колонок** — не требует XAML-декларации, полностью динамическое создание
2. **Умный поиск** — ищет по всем полям записи, а не только по отображаемым
3. **Визуальное выделение активности** — конвертер автоматически форматирует булевы поля
4. **Двойной клик** — ускорение работы (один клик вместо двух)
5. **Без данных** — корректная обработка случая, когда items пустой (создает колонки из firstField/secondField или Id)
6. **Case-insensitive** — поиск и сравнение без учета регистра

## Паттерн проектирования

- **Generic selector** — один диалог для всех справочников
- **Convention over configuration** — автоматическое определение полей из данных
- **MVVM-ready** — хотя реализован в code-behind, легко адаптируется под MVVM
- **Converter pattern** — преобразование данных на уровне привязки

Диалог демонстрирует эффективный подход к созданию универсальных компонентов UI через динамическую генерацию колонок DataGrid на основе метаданных данных.
